# 📚 简易图书馆管理系统 (Simple Library Management System)

本项目是一个基于 **C 语言（C23 标准）** 实现的命令行界面（CLI）图书馆管理系统。严格遵守**仅使用 C 标准库**的要求，实现了包括图书录入、查询、借阅管理、排序统计和数据持久化等核心功能。

## ✨ 核心功能

* **图书录入与存储**：
    * 图书数据采用**链表**结构存储于内存。
    * 支持 **ISBN 冲突检测**，确保图书唯一性。
    * 数据持久化采用**JSON 文件**格式（手动解析/序列化）。
* **图书查询**：
    * 支持 **ISBN 精确搜索**。
    * 支持 **书名/作者模糊搜索** (`strstr` 实现)。
* **借阅记录管理**：
    * 借阅和归还记录实时以**二进制文件**格式持久化存储，非内存模拟。
* **排序统计**：
    * 利用 `stdlib.h` 中的 `qsort` 函数，实现按**库存量**和**借阅量**的快速排序统计。
* **数据导出**：
    * 支持将图书数据导出为 **CSV 文件** 和 **JSON 文件**。
* **CLI 界面**：
    * 提供清晰的命令行交互界面，操作友好。

## ⚙️ 技术规范与模块分离

项目严格遵循模块化设计，以确保代码的可维护性和内存安全。

| 模块文件 | 职责描述 |
| :--- | :--- |
| `src/data.h/c` | **数据容器层**：定义 `Book` 和 `BorrowRecord` 结构体，实现链表节点创建、添加和内存释放 (`data_free_all`)。 |
| `src/store.h/c` | **文件接口层**：负责所有文件 I/O 操作，包括 JSON 读写（图书）、二进制读写（记录）和 CSV 导出。 |
| `src/logic.h/c` | **业务逻辑层**：实现 ISBN 冲突检测、搜索、借还书状态修改、以及排序逻辑（将链表转换为指针数组后使用 `qsort`）。 |
| `src/main.c` | **程序入口/CLI**：程序启动、数据加载、主菜单循环、用户输入处理和程序退出时的内存清理。 |

### 内存管理 (Valgrind 检测友好)

* 所有内存分配（`malloc`）均有空指针检查。
* 程序在退出前，通过调用 `data_free_all` 确保链表中的所有节点内存被正确释放，无泄漏。

### 代码标准

* **开发语言**：C语言 (C23标准)。
* **代码注释**：代码行注释率 **≥ 20%**，以确保代码可读性。
